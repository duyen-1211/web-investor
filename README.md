# 💼 Web Investor

A modern and responsive investment-themed website designed to showcase financial services, plans, and insights.  
This project was built to practice front-end web development skills, focusing on layout design, responsive UI, and clean component structure using React.

---

## 🔗 Live Demo
👉 [View the Project Here](https://lecture004.netlify.app/)

---

## 🚀 Features
- Elegant and professional homepage for investment services.  
- Section highlights for company overview, pricing plans, and customer benefits.  
- Fully **responsive layout** — optimized for all screen sizes.  
- Clean animations and transitions for a smooth user experience.  
- Developed using **ReactJS** and modern CSS styling techniques.  

---

## 🧩 Technologies Used
- **Framework:** ReactJS  
- **Languages:** HTML, CSS, JavaScript (ES6+)  
- **Styling:** Tailwind CSS / CSS Modules (if applicable)  
- **Tools:** Git, VS Code, Netlify for deployment

```bash
# 1. Clone the repository
